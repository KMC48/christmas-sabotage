# クリスマス粉砕大作戦 / Christmas Sabotage

> 聖夜を、平日に戻せ。

黒コートの工作員として街のイルミネーションに潜入し、暖色の電飾を蛍光白に変えていく、
縦持ちスマホ向けの潜入アクション。各スポットの「聖夜ムード」を 0% にすれば任務完了。
人には一切手を出さない。落とすのは照明だけ。

**▶ [ブラウザで遊ぶ](https://kmc48.github.io/christmas-sabotage/)**（スマホ推奨・インストール不要）

---

## 遊び方

| 操作 | スマートフォン | PC |
|---|---|---|
| 移動 | 画面左半分を押したままドラッグ | WASD / 矢印キー |
| 工作 | 画面右半分をタップ | スペースキー |
| 一時停止 | 左上のボタン | P / Esc |
| リトライ | 失敗画面の「もう一度」 | R |

1. イルミネーションに近づくと自動でロックされ、工作ボタンが赤く光る。
2. 工作すると **暖色 → 蛍光白**、または部分消灯になり、聖夜ムードが下がる。
3. **5秒以内**に次を決めるとコンボ。スコア倍率が上がり、工作時間も短くなる。
4. カップルが「撮るよ」「3、2、1」と構えたら、対象の上の**タイミングバー**に工作を合わせる。
   受付中に工作が**完了**すれば `JUST SABOTAGE +500`。
5. 警備員と監視カメラの視線に入り続けると発見ゲージが溜まる。**100 で失敗**。
6. 工作の音に気づいた警備員は**故障確認に向かう**。誘導すれば守られていた経路が空く。
7. 聖夜ムード **0%** でクリア。

全5ステージ。1プレイ 60〜90秒。

## 技術

- **依存ライブラリなし**。Canvas 2D ＋ DOM の HUD、Web Audio API による合成音のみ。
- 論理解像度 540×960（9:16）、DPR 対応。Pointer Events でマルチタッチ。
- 工作対象とステージは `game/game.js` 冒頭の `SAB` / `STAGES` のデータだけで完結する。
- 画像素材が 1 点も無くてもプロシージャル描画で成立する（`game/assets/` に置けば自動で差し替わる）。
- 記録・設定は localStorage。スコア記録はルール版ごとに分離。

```
game/
├── index.html   画面構造・UI・配色トークン
├── game.js      ゲームロジック全体
├── assets/      画像素材（21点）
├── tests/       受入条件の自動テスト（Playwright）
└── tools/       素材の前処理スクリプト
```

### テスト

```bash
pip install playwright && playwright install chromium
python game/tests/run_tests.py
```

実ブラウザで `index.html` を開き、固定 dt でゲーム内時間を進めて受入条件 T01〜T17 を検証する（63項目）。
