# クリスマス粉砕大作戦 ─ 実装版 README

仕様書 `クリスマス粉砕大作戦_ゲーム実装仕様書.md` のMVPを、**その場で遊べる形**で実装したもの。
体験改善版（v2）の指示書は `クリスマス粉砕大作戦_ClaudeCode実装指示書_v2.md`、企画意図は `企画書/クリスマス粉砕大作戦_企画書_v2.pdf`。
v3（成否リアクション・ラブラブオーラ・操作改善・全制覇エンディング）の指示書は `クリスマス粉砕大作戦_ClaudeCode実装指示書_v3.md`。

## 遊ぶ

### PCで遊ぶ
`game\index.html` をダブルクリック（ブラウザで開く）。
操作は **WASD / 矢印キーで移動、スペースキーで工作、Pで一時停止、Rでリトライ**。

### スマホで遊ぶ
公開URL（Artifact）を iPhone / Android のブラウザで開く。縦持ち推奨。
操作は2方式（v3）。タイトル画面の「操作」でいつでも切り替えられる。

| 方式 | 移動 | 工作 |
|---|---|---|
| スティック（標準） | 常に表示されたスティック（初期は右下）を押して倒す | 「工作」ボタン（初期は左下） |
| 主人公ドラッグ | 主人公を指でつかんで、行きたい場所へ動かす | 「工作」ボタン |

- 配置は「設定 → 操作位置」で 右下／中央下／左下、または「位置を調整」で自由配置。工作ボタンも動かせる。
- 画面の空いた場所をタップしても何も起きない（v2までの「右半分タップで工作」は廃止）。
- ローカルでは `game/index.html?control=drag` や `?layout=bl` で方式・配置を指定して開ける。

## 遊び方の芯

1. イルミネーションに近づくと対象が自動ロックされ、工作ボタンが赤く光る。
2. 工作すると **暖色 → 蛍光白**、または部分消灯になり、聖夜ムードが下がる。
3. **5秒以内に次の工作**を決めるとコンボ。スコア倍率が上がり、工作時間も短縮される（x3以上）。
4. カップルが「撮るよ」「3、2、1」と構えたら、**対象の上のタイミングバー**を見て工作を合わせる。
   受付（基準時刻の前後1.0秒）に**工作が完了**すれば `JUST SABOTAGE +500`。
5. 警備員・監視カメラの視線に入り続けると発見ゲージが溜まる。**100で失敗**。什器や人混みは視線を遮る。
6. 工作の音に気づいた警備員が**故障確認に向かう**。誘導すれば、守られていた経路が一時的に空く（ステージ2以降）。
7. 聖夜ムード **0%** でミッションクリア。1.8秒だけ余韻を見てから結果画面へ（タップでスキップ可）。

BGMは工作が進むほど楽器が減り、最後は無機質な点検音だけになる。

## 画像素材の扱い（組み込み済み）

納品された21点はすべて組み込み済み。次の処理を通してある。

- **スプライト14点**は、透過部分を除いた**外接矩形を事前計測**して `game.js` の `TRIM` に埋め込み、素材ごとの余白に関係なく「足元が接地した状態」で指定サイズに揃うようにした。表示サイズは `PROP_H` / `CHAR_H` の数値だけで調整できる。
- **工作後の見た目**は、読み込み時に各スプライトの「冷白色化版」「消灯版」をオフスクリーンで合成して差し替えている（`makeVariant`）。素材は点灯状態の1枚だけでよい。
- **背景5点とタイトル画像**は不透明なので **JPEG(q90) に変換**した。合計 38MB → 12MB。原本のPNGは `画像素材/` にそのまま残してある。
- 背景は「地面だけ」の俯瞰マップなので、その上にプロップと発光が重なる。地面は `rgba(10,14,28,.34)` で一段沈めて、光が主役になるようにしてある。
- `icon_1024.png` はアプリ化するとき用。ゲーム本体では使っていない。

素材を差し替えるときは、**同じファイル名で `game/assets/` に上書き**する。スプライトの余白を変えた場合だけ `tools/trim.json` を作り直し、`game.js` の `TRIM` を更新する。

## v2で追加した仕組み

### デートイベント（予告 → 受付 → オチ）

`STAGES` の `events` に、実在の対象とカップルを指す定義を書くだけで増やせる。

```js
events: [{
  id: 's1_photo', type: 'photo',   // photo | wreath | toast | tunnel | star
  target: 3,                        // このステージの targets の添字
  couple: 0,                        // このステージの couples の添字
  cues: ['撮るよ', '3', '2', '1'],
  payoff: '証明写真みたい……',
}],
```

時間の流れは `CFG.event` で一括調整する（予告3.0秒 / 受付は基準時刻の前後1.0秒 / 再予告まで6.0秒）。

- 判定は**押した時刻ではなく工作が完了した時刻**。吸着0.22秒と工作時間、コンボ短縮を含めた「完了する位置」を、対象の上のバーに緑の▲で示す。
- 強い予告は同時に1つだけ。対象が工作済みなら起動しない。無関係な照明を工作してもジャストにはならない。
- ジャスト判定の入口は `resolveJust()` 1か所。イベントを紐付けたカップルには旧来のハート判定を重ねない。

### コンボ待機猶予

狙って待つ間だけ、**コンボ時計を止める**（対象ごと1プレイ1回・累積最大1.2秒、`CFG.grace`）。
制限時間・発見ゲージ・イベントは止まらない。離れて戻っても回復しない。切れたコンボは復活しない。

### 警備員の調査行動

工作に成功すると、300px以内の巡回警備員を**1人だけ**呼ぶ（`CFG.guard`）。
反応0.45秒 → 対象へ移動（5秒で到達できなければ打ち切り）→ 現地確認1.8秒 → 元の巡回位置へ復帰 → 4秒のクールダウン。
経路は什器を避けて生成し、作れない対象は誘導対象にしない。プレイヤーを直視している警備員は誘導されない。

### クリアの確定と演出

ムードが0以下になった時点で**得点・記録を確定して保存**し、`finishing` 状態で1.8秒だけ見せてから結果画面へ。
演出中は失敗に落ちず、未工作の照明も勝手には変わらない。0.25秒以降の新しいタップ／スペースでスキップできる。

同じフレームで失敗と勝利が同時に成立した場合は、**失敗を優先**する（結果は二重に保存しない）。

### スコア記録のルール版

ステージ1の作り替えで旧版と同条件ではなくなったため、記録は `save.best2`（ルール版2）へ分離した。
旧版の `save.best` は読み取り専用で保持し、解放状況と設定はそのまま引き継ぐ。

## v3で追加した仕組み

### デートの結末（1プレイ1回で確定）

v2の「6秒後に再予告」はやめ、紐付いたデートは結末を1回で確定させる。判定は工作の**完了時刻**。

| 対応する照明の工作完了 | 結末 | カップル | 加点 |
|---|---|---|---|
| 予告の前 | 先回り成功 | 落胆（dejected） | 通常 |
| 予告中、t < 2.0 | 通常成功 | 落胆 | 通常 |
| 2.0 ≦ t ≦ 4.0 | ジャスト | 悲嘆（heartbroken） | 通常＋500（1回） |
| t = 4.0 までに未完了 | 妨害失敗 | 親密（lovey） | なし |
| 期限後に消灯 | 妨害失敗のまま | 親密のまま | 通常 |

境界ちょうど（2.0 / 4.0）は成功に含める。浮動小数の丸めで取りこぼさないよう `T_EPS = 1e-6` の幅を持たせている。
最初のジャストと最初の期限切れだけ、画面左端に反応カードを0.8秒出す。主人公の一言は0.45秒遅らせて無線欄に出す。

### ラブラブオーラ（消せる通行障害）

`STAGES[].auras` に `{ id, couple, source }` を書く。電源のライト（`source`）を工作すると、**完了と同じ更新で衝突が消え**、0.4秒の消滅演出が流れる。

- 半径56論理px。主人公の足元半径12pxと合わせた円で衝突し、接線方向へ滑る。移動は4px刻みに分割して判定するので、低FPSでも貫通しない。
- 輪の画像は `512 × R / 176` の大きさで描く（画像上の芯＝半径176px が、衝突の半径 R と一致）。
- オーラ越しにしか工作位置へ行けない対象はロックしない（「近づける側へ」と表示）。
- オーラは視線を遮らない。警備員や通行人には効かない。
- 配置：ステージ1〜3と5に1か所、ステージ4に2か所。どれも迂回でき、電源は輪の外から工作できる（テストA07で全ステージを検証）。オーラを持つカップルはその場に留まる。

### 主人公と結果画面

- 勝利確定の0.5秒後から主人公が得意顔、敗北確定で悔し顔（移動中の見た目には使わない）。
- 結果画面の上部に結果絵（成功／失敗／全制覇）。縦画面でも切り抜かず `contain` で全体を見せる。
- 敗北は1.2秒だけ悔し顔を見せてから失敗画面へ（0.25秒以降のタップでスキップ）。

### 全ステージ制覇の破局エンディング

5ステージすべてにクリアの記録（旧版の記録も証跡として扱う）がそろった勝利の1回目だけ、通常の結果の代わりに約5.5秒の最終演出を流す。
暗転 → 親密から破局へ → 「……もう、終わりにしよう」「……ああ」 → 最終絵 → 主人公「任務、完了」。
0.25秒以降はタップでスキップでき、解放は演出を待たずに保存される。以後はステージ選択の「エンディングを見る」と結果画面から何度でも再生できる（記録・得点には触れない）。

### 記録（ルール版3）

デートの結末が1回で確定するようになり点数条件が変わったため、ベスト記録は `save.best3` に分けた。`best`（版1）・`best2`（版2）・解放状況・設定はそのまま残る。
操作設定は `save.controls`。v2の「左利き」は、旧コードが実際に移動へ割り当てていた側で移行する（OFF＝左側スティック → 左下、ON → 右下）。新規プレイヤーは右下から。

### 操作比較メモ

プレイごとに「初めて動くまで／初めて工作するまでの秒数」「工作の中断回数」「オーラへの接触回数」を端末内に記録し、「設定」に方式別の平均を表示する。外部には送らない。

## ステージを足す・調整する

`game/game.js` 冒頭の2つのデータだけで完結する。コードは触らなくていい。

**工作対象の性能**（`SAB`）
```js
tree: { name:'街路樹ライト', mood:8, dur:0.45, score:300, effect:'white' },
//     mood=聖夜ムード減少量 / dur=工作秒数 / effect=white|off|partial|half|star
```

**ステージ**（`STAGES`）
```js
{
  id:6, name:'新ステージ', theme:'テーマ', style:'street',  // street|market|restaurant|park|tower
  time:85, worldH:2200, start:{x:270,y:2080},
  moodMul:1.0,                                              // ムード減少の倍率（ステージ1のみ1.5）
  rank:{S:12000,A:9000,B:6000},
  targets:[ T('tree',96,1930), T('heart',270,1540) ],       // 合計moodが100以上になるように
  obstacles:[{x:200,y:1800,w:140,h:44}],                    // 視線を遮る什器
  guards:[{x:270,y:1620,type:'guard',mode:'patrol',pts:[[120,1620],[420,1620]],spd:42,range:210,fov:0.46}],
  couples:[{pts:[[140,1750],[400,1620]],spd:18}],           // イベントの担当・汎用リアクション
  crowd:8,
  investigate:true,                                         // 警備員の調査行動を有効にする
  events:[{ id:'s6_photo', type:'photo', target:0, couple:0,
            cues:['撮るよ','3','2','1'], payoff:'証明写真みたい……' }],
}
```

- 座標系は **横540 × 縦worldH**（上が奥、下が手前）。プレイヤーは下から上へ進む。
- 難易度は仕様書21章どおり、**視線の重なり・対象の配置・制限時間**で調整する。敵を速くしない。
- 対象の合計moodを110〜130にしておくと、ルート選択の自由が生まれて周回が面白くなる。
- ムードの倍率は `moodMul` でステージ側に持たせる。`SAB` の共通定義は変更しない。

## 既知の制約

- ブラウザの仕様上、**音は画面を一度タップするまで鳴らない**（初回タップで自動的に有効化される）。
- 記録は端末のローカル保存。別の端末やシークレットウィンドウには引き継がれない。
- 振動はAndroid Chromeのみ動作。iOS Safariは非対応（設定でOFFにできる）。
