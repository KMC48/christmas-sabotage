作成日：2026-09-26

## 使い方

1. このZIPを展開します。
2. `game/assets/` 内のPNG6点を、既存ゲームの `game/assets/` にコピーします。
3. ブラウザをCtrl+F5で再読み込みします。

依頼書で指定された6つのファイル名を使用しています。

## 画像仕様

- 6点とも実際のアルファチャンネルを持つ背景透過PNGです。市松模様や色付き背景は含みません。
- 人物の縦横比を保ち、上下左右の余白と接地面下の空白を詰めています。
- 高さは512pxに統一。依頼書のサイズは推奨値のため、タイトなトリミングを優先し、横幅は各ポーズの自然な形に合わせています。
- 地面の影、文字、ロゴ、懐中電灯の光のビーム、制御盤は画像に含めていません。
- 主人公の後ろ脚など、ポーズとコートの重なりで隠れる部分があります。
- 固定の幅・高さで画像を描画する実装では、人物が横に伸びないよう元画像の縦横比を保ってください。表示サイズの確認はゲーム実機で行ってください。

## 同梱ファイル

- `game/assets/`：ゲームに組み込むPNG6点
- `asset_preview.jpg`：一覧確認用。濃紺の背景とファイル名はこのプレビューだけにあります。
- `asset_manifest.json`：画像サイズとSHA-256
- `generation_prompts.md`：生成時の指定内容

## 確認済みの項目

指定ファイル名、RGBA、透明画素、余白のトリミング、6点の点数、明色・濃色背景での切り抜き状態を確認しました。実際のゲームの描画サイズとポーズ切り替えは、この素材制作作業では未確認です。
