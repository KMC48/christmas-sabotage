# クリスマス粉砕大作戦 v3 — 追加素材・実装指示

12種類の素材と、Claude Codeへ渡す実装指示書です。ゲーム本体を改修した成果物ではありません。

## 使い方

1. ZIPを展開し、game/assets/v3/ を既存プロジェクトの素材フォルダへコピー。
2. 「クリスマス粉砕大作戦_ClaudeCode実装指示書_v3.md」をプロジェクトへ置く。
3. 指示書末尾の「そのまま渡せる開始文」をClaude Codeへ渡す。

素材画像の文字・操作UIはゲーム側で描画してください。既存素材は置換せず追加する構成です。追加先のパスが違う場合はローダーとmanifestを合わせてください。

## 入っているもの

- カップル4差分：落胆、悲嘆、親密、破局。
- 主人公2差分：任務達成、任務失敗。
- 結果・エンディング絵3点：通常成功、失敗、全ステージ制覇の破局。
- オーラFX3種類：輪、ハート、消滅。それぞれPNGとSVG。
- 実装指示書、assets_manifest.json、generation_prompts.json。
- character_preview_v3.jpg、ending_fx_preview_v3.jpg：確認用一覧。ゲーム素材としては使用しません。
- QA_NOTES.md：今回確認した範囲。

## 今回の方針

時間内の工作でカップルが落胆し、期限を逃すと親密になる。照明を切ると通行障害のオーラが消える。全ステージ制覇では破局して絶望する結末。通常成功とは別の最終演出です。

操作は「常時表示スティック、右下を初期位置、右下・中央下・左下のプリセット＋自由配置」を推奨。工作ボタンも配置調整できる指示にしています。直接ドラッグも比較し、Claude Code自身の意見を報告するよう明記しました。

## サイズと描画

人物は高さ768px、透明の安全余白12px。縦横比を保ち、足元アンカーと身体の描画高さを合わせてください。結果絵は1536×1024。縦画面では横長パネル内で全体表示を推奨。

FXの輪は512×512、輪の中心(256,256)、芯の半径176px。ゲーム内半径Rなら描画サイズは512×R/176。画像アルファを物理判定に使わず、コード内の円判定と対応させます。

## 出典・再生成

人物の顔と衣装は既存のplayer_agent.png、npc_couple.png、title_key.pngを参照。生成プロンプトはgeneration_prompts.jsonに収録。参照元画像は従来の「ゲーム素材一式.zip」にあります。FXは今回作成したSVGです。新規画像は文字を含みません。
