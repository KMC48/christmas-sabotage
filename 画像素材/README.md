# クリスマス粉砕大作戦 ゲーム素材セット

制作依頼書に掲載された全21点に加え、主人公の全身タイトル画像の別案1点を収録しています。作成済みの主人公・街路樹を含みます。

## 配置方法

1. ZIPを展開します。
2. `game/assets/` 内のPNGを、既存ゲームの同名フォルダへコピーします。
3. ファイル名は変更せず、ブラウザを再読み込みします。古い画像が残る場合はCtrl+F5を試してください。

同名素材が既にある場合は、必要に応じて先にバックアップしてください。

## 収録内容

- キャラクター4点：主人公、警備員、カップル（2人で1組）、通行人。
- 工作対象10点：街路樹、大型ツリー、ハート、トンネル、フォトスポット、屋台、リース、窓、水面ライト、LED。
- ステージ背景5点：並木道、マーケット、レストラン、海辺の公園、展望台。
- アプリ用2点：1024pxアイコン、縦長タイトル画像。

キャラクターと工作対象の14点は実際のアルファチャンネルを持つ透過PNGです。
背景・アイコン・タイトルの7点は不透明です。素材自体に文字・ロゴは入れていません。
寸法・透過の有無・各ファイルのSHA-256は `asset_manifest.json` で確認できます。
`asset_preview.jpg` は一覧確認用で、ゲームへの組み込みには使用しません。

## 実装時の扱い

- 工作対象はすべて点灯状態です。消灯・白色化・強い発光の重ね描きはゲーム側で処理します。
- 透過素材は足元／土台を下端へ合わせています。基本アンカーは画像下端の中央です。
- キャラクターは各1枚の静止画です。歩行・工作アニメーションのフレーム集ではありません。
- 背景は地面を描いた素材です。全景を残すため、生成原画を指定された縦長キャンバスへリサイズしています。
- 背景画像だけでは歩行範囲・当たり判定は変わりません。既存ステージの座標、通路、水域、オブジェクト配置に合わせて実機で確認してください。
- タイトル画像の下側にはタイトル文字・ボタン用の暗い余白があります。
- ゲーム本体が添付されていないため、画像の寸法・透過・ファイル整合性まで確認済みです。実ゲームへの組み込み動作は未検証です。

## 制作について

添付の主人公画像と制作依頼書を基準に画像生成ツールで制作しました。
一部の素材は依頼書で指定された単色背景から透過処理し、指定寸法へ調整しています。
今回生成した素材のプロンプトは `generation_prompts.md` に収録しています。

## 主人公の全身画像修正

`game/assets/title_key.png` は、ズボン・両脚・靴まで描いた全身版へ更新しました。
別案は `extras/title_key_fullbody_01.png` です。どちらも1080×1920pxで、足元をフェードアウトしていません。
別案を使う場合は、ファイル名を `title_key.png` にして `game/assets/` へ配置してください。
